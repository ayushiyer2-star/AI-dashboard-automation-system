**Project Title: TRISTHA — Enterprise AI Dashboard Automation**

TRISTHA is a web-based business intelligence application designed to automate dashboard creation and data analysis. It enables users to import structured data from files, prepare the data, generate interactive visualizations, and obtain analytical insights through a user-friendly interface.

The project is developed using HTML, CSS, and JavaScript, with Chart.js for visualizations, SheetJS for spreadsheet processing, and PptxGenJS for presentation generation. It also provides modules for predictive analytics, what-if analysis, financial reporting, data-source management, and Jira integration.

The main objective of the project is to reduce manual reporting effort, simplify data analysis, and help organizations make informed decisions using visual and analytical information. The application demonstrates how dashboard automation and natural-language interaction can make business intelligence more accessible and efficient.
